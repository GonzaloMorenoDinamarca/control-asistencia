🟢 Configurar Supabase

Supabase es una alternativa gratuita a Firebase, más simple y confiable. Solo necesitas configurarlo una vez — completamente gratuito hasta 500MB.

1
Ve a supabase.com → Start for free → inicia sesión con GitHub o Google.
2
Clic en "New project". Nombre: asistencia-liceo. Elige una contraseña para la base de datos y selecciona región South America (São Paulo). Espera ~2 minutos.
3
Ve a SQL Editor (menú lateral) → New query → pega y ejecuta este código:
create table if not exists app_data ( id uuid references auth.users on delete cascade primary key, state jsonb default '{}', updated_at timestamptz default now() ); alter table app_data enable row level security; create policy "own_data" on app_data for all using (auth.uid() = id) with check (auth.uid() = id);
Luego haz clic en RUN (▶).
4
Ve a Project Settings → API. Copia la Project URL y la anon public key y pégalas abajo.

Ejemplo: https://abcdefghij.supabase.co

La clave que empieza con "eyJ..." o "sb_publishable_..."
